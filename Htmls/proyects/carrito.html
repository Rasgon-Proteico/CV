Carrito autónomo


Carrito autónomo realizado con arduino


Surgido de un proyecto de finales de semestre, en el desenlace de ese proyecto colaborativo que tuvimos, hubo distintas inconformidades, y una de ellas fué que el carrito autónomo que se había hecho no funcionaba correctamente, por lo cual me propuse a hacer uno desde cero, con la finalidad de que este si funcionara correctamente


Materiales

  • Arduino Uno
  • Sensor ultrasónico
  • Motor DC (2)
  • Driver L298N
  • Batería 3.7V modelo 1650 (2)
  • Chasis de carrito
  • Ruedas (2)
  • Rueda loca (1)

Armado


El armado del carrito es bastante sencillo, se debe de colocar el chasis, el chasis es a elección de cada quien, en mi caso usé una base inspirada en los kits comerciales de arduino, así mismo, se debe hacer espacio para los componentes, en mi caso, el sensor ultrasónico lo coloqué en la parte frontal del carrito, y los motores en la parte trasera, así mismo, se debe de colocar la batería y el driver L298N, el cual es el encargado de controlar los motores.


Programación


La programación del carrito es bastante sencilla, se debe de utilizar la librería NewPing para el sensor ultrasónico, y se debe de utilizar la librería Servo para controlar los motores, así mismo, se debe de utilizar la función millis() para controlar el tiempo de espera entre cada medición del sensor ultrasónico, y se debe de utilizar la función analogWrite() para controlar la velocidad de los motores, así mismo, se debe de utilizar la función digitalWrite() para controlar la dirección de los motores, y se debe de utilizar la función delay() para controlar el tiempo de espera entre cada movimiento del carrito.
